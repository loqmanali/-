#### **مقدمة المشروع**

التطبيق المقترح هو حل رقمي شامل لإدارة صيانة المساجد. الهدف منه هو تسهيل عمليات العناية بالمسجد، الإصلاحات، وإدارة التكاليف.  
سيخدم التطبيق عدة فئات من المستخدمين:

- الأئمة
    
- العمال
    
- الجهات الإدارية
    
- شركات الصيانة  
    كل هؤلاء سيتمكنون من استخدام منصة موحدة لإرسال طلبات الصيانة، متابعة حالتها، تعيين المهام، وإدارة التكاليف.
    

---

#### **الخصائص الرئيسية**

1. **إدارة طلبات الصيانة**
    
    - المستخدمون يمكنهم تقديم طلبات صيانة مع تفاصيل مثل: نوع الطلب، الأولوية.
        
    - تتبع حالة الطلب باستمرار.
        
    - تعيين الطلبات لشركات الصيانة المناسبة.
        
    - نظام مراجعة لإغلاق الطلبات بعد التأكد من التنفيذ.
        
2. **إدارة صلاحيات المستخدمين**
    
    - لكل فئة من المستخدمين (إمام، عامل، إدارة، شركة صيانة) صلاحيات محددة.
        
    - واجهة استخدام خاصة بكل دور حسب وظيفته.
        
3. **إدارة التكاليف**
    
    - متابعة تكاليف الصيانة المسجلة.
        
    - إصدار تقارير تحليلية عن المصروفات.
        
    - مراقبة الميزانية لضمان عدم تجاوزها.
        
4. **التواصل والإشعارات**
    
    - إشعارات فورية لتحديثات الحالة المهمة.
        
    - رسائل داخل التطبيق لتسهيل التواصل بين المستخدمين.
        
5. **التقارير والتحليلات**
    
    - لوحات عرض لأداء عمليات الصيانة.
        
    - تقارير تحليلية لتكاليف الصيانة.
        
    - تتبع سجل عمليات الصيانة للمسجد.
        

---

#### **النهج الفني**

- **تطبيق الجوال**: سيتم بناؤه باستخدام إطار عمل Flutter لتطوير تطبيق يعمل على iOS وAndroid معًا.
    
- **الخلفية (Backend)**: نظام خلفي مخصص باستخدام واجهات RESTful API.
    
- **قاعدة البيانات**: قاعدة بيانات قوية لتخزين المعلومات بشكل آمن.
    
- **تصميم واجهة المستخدم (UI/UX)**: باتباع معايير تصميم Shadcn UI، مع تحسين خاص لدعم اللغة العربية.
